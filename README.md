# ANSH FF PREMIUM PANEL

A simple Android Studio project for a black-and-gold Free Fire settings companion.

## Features
- Sensitivity preset sliders saved locally on the device
- HUD/control preference toggles
- Device performance reminders
- Aim-training checklist
- Reset settings button

## Build an APK
1. Install Android Studio on a computer.
2. Open this project folder in Android Studio.
3. Let Gradle sync complete.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location.

This app is a settings companion only. It does not interact with or modify Free Fire, automate gameplay, bypass anti-cheat, or provide cheats. Sensitivity values are starting points, not guaranteed optimal settings.
